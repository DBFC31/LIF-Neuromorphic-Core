# LIF Neuromorphic Core
This repository contains a Verilog implementation of a spiking neural network (SNN) neuromorphic core for function approximation. The top-level network module instantiates a parameterizable array of neuron modules, each a Leaky Integrate-and-Fire (LIF) neuron with configurable threshold, leak shift, and bit width, driving a readout_rate_code module that decodes spike trains via rate coding over a fixed time window into a signed integer output value. Input weights, biases, and readout weights are loaded from external .mem files into inferred block RAM (M9K-style), keeping the datapath fully combinational/pipelined per timestep with no on-chip training logic. A Verilog testbench (network_TB) sweeps a 2D input grid to validate the circuit's output surface against a target function. The design targets Intel/Altera FPGAs and is structured for easy resizing of neuron count, bit widths, and timestep count via module parameters.
